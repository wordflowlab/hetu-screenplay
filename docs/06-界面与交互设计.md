# 界面与交互

## 1. 工作面

独立全幅页面，顶部合并标题、返回、方案选择、保存／历史与让AI处理。宿主顶栏与侧栏收起，由navigation=integrated接入；插件保留一处返回工作台。主要区域为可折叠结构目录与阅读详情，专业专题用标签切换。

## 2. 作者操作

默认阅读真实成果，提供普通表单的可选局部编辑，不以JSON编辑器作为作者入口。让AI处理携带当前固定方案、节点、已有成果和目标；复杂结构操作通过机器动作，作者无需操作所有专业字段。未知及冲突保留输入，先查询原键，再明确比较并重新准备。

## 3. 专题

结构、人物与伏笔、正文接续、意见记录、历史比较与交付分别查看；场次详情显示目的、冲突、行动与变化。人物与伏笔按关联节点显示；未采用候选与已发生剧情保持标识。

## 4. 视觉与无障碍

共享Radix浅暗主题与连续渐变，12／14／20px界面和18px长文，0.5px边框。窄窗收起目录而不隐藏成果；键盘可切换标签、定位条目、编辑与返回。加载、空、错误、冲突、未知恢复与成功就地反馈。真实渲染、计算尺寸和行为分别验证，评分只代表已观察范围。
