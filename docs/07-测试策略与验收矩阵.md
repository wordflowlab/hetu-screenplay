# 测试与验收

## 1. 层级

单元覆盖Schema、领域不变量、专业操作、历史比较、导出、预算和恢复；应用测试注入内存Core，验证一次权威写及来源核验失败不写；机器集成使用真实河图稳定MCP和CLI；界面使用浏览器及同版Electron分别取证。

## 2. 必验矩阵

| 范围 | 正例 | 负例 |
| --- | --- | --- |
| 数据与身份 | 同名、可选层级、固定历史 | 重复ID、环、换类型、删除旧身份 |
| 版本与操作 | CAS、原键重放、分支比较 | 同键异参、旧基线、错误摘要 |
| 来源 | 固定宿主正文／素材回读 | 跨作品、修订摘要错、未知实体 |
| 专业用例 | 05全部旅程的可执行部分 | 未完成、未知、候选与作者决定混用 |
| 机器生态 | 安装、发现Skill、读写、停用／重启用／卸载 | 旧能力、错误作品、停用调用 |
| 界面 | 浅暗、窄窗、键盘、编辑、返回 | 失效加载、未知保存、CAS保留稿 |
| 交付 | 固定完整JSON／Markdown与摘要 | 变动分页、越界路径、缺依赖 |

## 3. 证据边界

单元数量不证明故事或电影质量。实际媒体解码、内容观看、作者认可与接收方工程恢复分别报告；真实付费工具未执行不能由演示媒体代替。每个失败保留日志并修复相应根因，不通过扩大超时掩盖合同错误。
