# 剧本推进与用例

| 场景 | 输入与步骤 | 必须回读 |
| --- | --- | --- |
| 原创电影 | 独立剧本WorkRef，根→段落／场次；明确主题和结尾 | 全作与场次固定方案 |
| 系列或短剧 | 按需要根→季／集→场次，不创建空上游 | 分集目标与场次转折 |
| 旧稿复盘 | 固定原稿来源，逐范围登记read／partial／unread；区分原有事实与新推断 | 完整覆盖及过去结构 |
| 改编 | 固定获权来源，记录改编取舍，不改原著 | 来源与剧本各自固定身份 |
| 人物与伏笔 | 人物选择、代价、认知落到节点；关系与伏笔有明确出场／回收 | 相同稳定ID与范围投影 |
| 正文接续 | 准备全作→下一集→场次；宿主创建正式分集，map_episode，准备参考稿任务 | read_manuscript、Fountain工作稿和候选 |
| 返工 | 读取固定原稿与意见，保存参考稿下一修订，提交并回读 | 旧稿仍在，作者稿未被自动替换 |
| 多方案比较 | fork_project与compare_versions，保留固定来源 | 两端revision与摘要 |

方法先读已有成果和作者约束，再生成具体剧情。不能仅做空泛总纲；但也不强制电影建季／集。采纳与定稿通过宿主作者决定，不是专业方案保存的副作用。
